## 1. Backend — Service Layer

**Principe appliqué :** *"Each module has a dedicated Service class. Controllers stay thin. Controllers should only: validate → call service → return response."*

### 9 classes Service créées dans `app/Services/`

| Fichier | Responsabilités extraites |
|---|---|
| `AuthService.php` | `registerOrganisation()`, `registerClient()`, `login()`, `logout()`, `generateUniqueSlug()` |
| `BienService.php` | `index()`, `store()`, `update()`, `destroy()`, `uploadImages()`, `deleteImage()` |
| `AnnonceService.php` | `index()`, `store()`, `update()`, `destroy()`, `publier()`, `archiver()` |
| `ContratService.php` | `index()`, `store()`, `update()`, `destroy()`, `uploadFichier()` |
| `ClientService.php` | `index()`, `store()`, `update()`, `destroy()` |
| `EmployeService.php` | `index()`, `store()`, `update()`, `destroy()` |
| `FactureService.php` | `index()`, `store()`, `update()`, `destroy()`, `marquerPayee()` |
| `InvestissementService.php` | `index()`, `store()`, `update()`, `destroy()` |
| `OrganisationService.php` | `index()`, `activer()`, `desactiver()`, `destroy()` |

### 8 contrôleurs refactorisés

Tous les contrôleurs utilisent maintenant l'injection de dépendance via constructeur :

```php
public function __construct(private BienService $service) {}
```

Avant (dans le contrôleur) :
```php
$data = $request->validate([...]);
$data['organisation_id'] = $this->orgId();
return new BienResource(Bien::create($data));
```

Après (dans le contrôleur) :
```php
return new BienResource($this->service->store($this->orgId(), $request->validated()));
```

### ❌ Ce qui reste à faire pour que l'application soit prête

#### Priorité 1 — Migration Frontend vers les nouveaux patterns

Chaque page du dashboard (`/dashboard/biens`, `/dashboard/annonces`, etc.) et du backoffice (`/admin/organisations`) doit être migrée pour :

1. **Remplacer** les `useState + useEffect + axios.get(...)` par le hook correspondant (`useBiens()`, `useAnnonces()`, etc.)
2. **Remplacer** les tableaux HTML manuels par `<DataTable>` avec les colonnes configurées
3. **Remplacer** les badges statut inline par `<StatusBadge status={...} />`
4. **Remplacer** les `<button>` inline par `<Button variant="..." />`
5. **Remplacer** les `href="/dashboard/biens/..."` en dur par `ROUTES.dashboard.biens`
6. **Remplacer** les modales custom par `<Modal>`

C'est un travail mécanique sur ~20 pages.
